# Vinted Tracker Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local web dashboard (`python -m vinted_tracker dashboard` → http://localhost:8000) showing tracker stats, charts and a live product table, with an Excel download and a settings panel that changes what the running tracker follows (brand groups, product types, sizes, conditions) without restarts.

**Architecture:** A FastAPI app in `vinted_tracker/web/` renders one page plus htmx fragments that poll every 30 s, all reading the shared PostgreSQL database. Watch settings move from `config.yaml` into a `watch_settings` table, which the tracker re-reads on every loop tick. The tracker's heartbeat goes into a `tracker_status` table. Brand search uses a short-lived Playwright browser, with results cached in `brand_cache`.

**Tech Stack:** Python 3.13, FastAPI, uvicorn, Jinja2, htmx 2.0.4 and Chart.js 4.4.1 (vendored), psycopg 3, PostgreSQL 18, pytest + FastAPI TestClient.

**Spec:** `docs/superpowers/specs/2026-10-05-dashboard-design.md` (builds on `docs/superpowers/specs/2026-09-27-vinted-sell-time-tracker-design.md`)

## Global Constraints

- Windows 11 + PowerShell. Commands run from `C:\Users\calin\Desktop\VintedScraper`, with Python at `.venv\Scripts\python` (`.venv/Scripts/python` in bash).
- The dashboard binds to **`127.0.0.1` only**, default port **8000**, with a `--port` option. There is no login in this project.
- **One page:** status bar, 5 tiles, 4 charts, product table; settings in a side panel. htmx and Chart.js are **vendored** under `vinted_tracker/web/static/` (no CDN at runtime).
- Fragments poll **every 30 s**; charts refresh every 5 min. The product table shows **50 rows per page**, newest first.
- **Tracker "stopped"** = heartbeat ≥ **10 min** old, unless health is `blocked` and `paused_until` is in the future.
- **Charts** show only buckets with **≥ 3** certain sales; otherwise "Not enough sold items yet (needs ≥ 3 per bar)".
- **Settings rules:** at least 1 group; group names non-empty and unique (case-insensitive); each group has ≥ 1 brand; ≥ 1 product type; ≥ 1 condition; ids must come from `vinted_ref` (brands come from the lookup). Empty sizes = no size filter.
- **Settings changes apply to new discoveries only.** Already-tracked items continue. Out-of-scope items are excluded from every dashboard view.
- Every timestamp is tz-aware UTC in the DB; the UI shows Europe/Bucharest time.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Controller (main session) updates the progress page https://claude.ai/artifact/5TZhDzeGjVt8wVTDqWcpj3 at the end of each task.
- **The running tracker must keep working.** It picks up code changes only when restarted (`scripts\stop_tracker.ps1`, then `Start-ScheduledTask -TaskName VintedTracker`), which Task 3 does.

## Deviations from the spec (intentional, small)

1. **Leaf → product-type map:** embedded as data in `vinted_ref.py` (probed 2026-10-04, 104 sub-categories) instead of generated by a script. The map changes rarely, and a script would need the browser.
2. **Separate dashboard queries:** `stats.py` has its own queries for tiles, charts and table, and `export.py` is left unchanged. Sharing SQL would mean rewriting a tested module for no user-visible gain.
3. **Conditions 2/3/4 are verified:** 2 = Foarte bună, 3 = Bună, 4 = Satisfăcătoare (probed 2026-10-04), so the panel offers all five.
4. **`paused_until` added to the heartbeat** so a long Vinted back-off isn't shown as "stopped".

## Review Focus

1. **The dashboard opened before the tracker ever ran** (no settings row, no heartbeat, no items) → the page renders with "hasn't reported yet" and empty states, not a 500. → Task 6 `test_page_renders_on_empty_database`, Task 7 `test_settings_panel_without_settings`.
2. **Listing titles or brand names containing HTML/quotes** (`<script>`, `"`, `Stüssy`) → shown as text, never executed. → Task 6 `test_products_escape_html_in_titles`, Task 7 `test_brand_results_escape_titles`.
3. **A group renamed or added in the settings** → the tracker treats it as a new search: first poll is a baseline and nothing old is mass-tracked. → Task 3 `test_renamed_group_starts_with_a_baseline`.
4. **A long Vinted back-off (up to 4 h)** → shown as "Blocked … until HH:MM", not "stopped". → Task 4 `test_tracker_state_blocked_pause_is_not_stopped`.
5. **All sizes unticked** → no size filter (all sizes tracked), not "track nothing". → Task 3 `test_catalog_url_without_sizes_has_no_size_filter`, Task 2 `test_empty_sizes_are_valid`.

```python
def get_watch_settings(conn: psycopg.Connection) -> tuple[int, dict] | None:
    row = conn.execute("SELECT version, data FROM watch_settings WHERE id = 1").fetchone()
    return None if row is None else (row["version"], row["data"])


def save_watch_settings(conn: psycopg.Connection, data: dict, now: datetime) -> int:
    return conn.execute(
        """
        INSERT INTO watch_settings (id, data, version, updated_at) VALUES (1, %s, 1, %s)
        ON CONFLICT (id) DO UPDATE
            SET data = EXCLUDED.data, version = watch_settings.version + 1, updated_at = EXCLUDED.updated_at
        RETURNING version
        """,
        (Jsonb(data), now),
    ).fetchone()["version"]


def set_tracker_status(conn: psycopg.Connection, data: dict, now: datetime) -> None:
    conn.execute(
        """
        INSERT INTO tracker_status (id, data, updated_at) VALUES (1, %s, %s)
        ON CONFLICT (id) DO UPDATE SET data = EXCLUDED.data, updated_at = EXCLUDED.updated_at
        """,
        (Jsonb(data), now),
    )


def get_tracker_status(conn: psycopg.Connection) -> tuple[dict, datetime] | None:
    row = conn.execute("SELECT data, updated_at FROM tracker_status WHERE id = 1").fetchone()
    return None if row is None else (row["data"], row["updated_at"])


def get_brand_cache(conn: psycopg.Connection, keyword: str) -> tuple[list, datetime] | None:
    row = conn.execute("SELECT results, fetched_at FROM brand_cache WHERE keyword = %s", (keyword,)).fetchone()
    return None if row is None else (row["results"], row["fetched_at"])


def put_brand_cache(conn: psycopg.Connection, keyword: str, results: list, now: datetime) -> None:
    conn.execute(
        """
        INSERT INTO brand_cache (keyword, results, fetched_at) VALUES (%s, %s, %s)
        ON CONFLICT (keyword) DO UPDATE SET results = EXCLUDED.results, fetched_at = EXCLUDED.fetched_at
        """,
        (keyword, Jsonb(results), now),
    )

"""What the tracker follows (brand groups, product types, sizes, conditions).

Stored in the `watch_settings` table, edited in the dashboard, re-read by the tracker every loop tick.
"""
from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime

import psycopg

from . import db
from .config import Config, Query
from .vinted_ref import CONDITIONS, LETTER_SIZES, PRODUCT_TYPES, SEED_BRAND_TITLES, WAIST_SIZES


class SettingsError(ValueError):
    def __init__(self, errors: list[str]) -> None:
        super().__init__("; ".join(errors))
        self.errors = errors


@dataclass(frozen=True)
class Brand:
    id: int
    title: str


@dataclass(frozen=True)
class Group:
    name: str
    brands: tuple[Brand, ...]


@dataclass(frozen=True)
class WatchSettings:
    groups: tuple[Group, ...]
    catalog_ids: tuple[int, ...]
    size_ids: tuple[int, ...]
    status_ids: tuple[int, ...]

    def queries(self) -> tuple[Query, ...]:
        return tuple(
            Query(
                name=g.name,
                catalog_ids=self.catalog_ids,
                brand_ids=tuple(b.id for b in g.brands),
                status_ids=self.status_ids,
                size_ids=self.size_ids,
            )
            for g in self.groups
        )

    def allowed_conditions(self) -> tuple[str, ...]:
        return tuple(CONDITIONS[s] for s in self.status_ids if s in CONDITIONS)

    def to_json(self) -> dict:
        return {
            "groups": [{"name": g.name, "brands": [{"id": b.id, "title": b.title} for b in g.brands]} for g in self.groups],
            "catalog_ids": list(self.catalog_ids),
            "size_ids": list(self.size_ids),
            "status_ids": list(self.status_ids),
        }

    @classmethod
    def from_json(cls, data: dict) -> "WatchSettings":
        return cls(
            groups=tuple(
                Group(str(g["name"]), tuple(Brand(int(b["id"]), str(b["title"])) for b in g["brands"]))
                for g in data["groups"]
            ),
            catalog_ids=tuple(int(x) for x in data["catalog_ids"]),
            size_ids=tuple(int(x) for x in data["size_ids"]),
            status_ids=tuple(int(x) for x in data["status_ids"]),
        )


def validate(s: WatchSettings) -> None:
    errors: list[str] = []
    if not s.groups:
        errors.append("Add at least one brand group.")
    seen: set[str] = set()
    for g in s.groups:
        name = g.name.strip()
        if not name:
            errors.append("Every group needs a name.")
            continue
        if name.casefold() in seen:
            errors.append(f"Two groups are called '{name}'.")
        seen.add(name.casefold())
        if not g.brands:
            errors.append(f"Group '{name}' needs at least one brand.")
    if not s.catalog_ids:
        errors.append("Pick at least one product type.")
    errors += [f"Unknown product type {c}." for c in s.catalog_ids if c not in PRODUCT_TYPES]
    errors += [f"Unknown size {z}." for z in s.size_ids if z not in LETTER_SIZES and z not in WAIST_SIZES]
    if not s.status_ids:
        errors.append("Pick at least one condition.")
    errors += [f"Unknown condition {c}." for c in s.status_ids if c not in CONDITIONS]
    if errors:
        raise SettingsError(errors)


def seed_from_config(cfg: Config) -> WatchSettings:
    """Today's config.yaml watchlist: all its groups and brands, every clothing type, no size filter."""
    groups = tuple(
        Group(q.name, tuple(Brand(b, SEED_BRAND_TITLES.get(b, f"Brand {b}")) for b in q.brand_ids)) for q in cfg.queries
    )
    first = cfg.queries[0] if cfg.queries else None
    status_ids = first.status_ids if first and first.status_ids else tuple(
        s for s, name in CONDITIONS.items() if name in cfg.allowed_conditions
    ) or (6, 1)
    return WatchSettings(
        groups=groups,
        catalog_ids=tuple(PRODUCT_TYPES),
        size_ids=first.size_ids if first else (),
        status_ids=status_ids,
    )


def load(conn: psycopg.Connection) -> tuple[int, WatchSettings] | None:
    row = db.get_watch_settings(conn)
    return None if row is None else (row[0], WatchSettings.from_json(row[1]))


def save(conn: psycopg.Connection, s: WatchSettings, now: datetime) -> int:
    validate(s)
    return db.save_watch_settings(conn, s.to_json(), now)


def ensure_seeded(conn: psycopg.Connection, cfg: Config, now: datetime) -> tuple[int, WatchSettings]:
    loaded = load(conn)
    if loaded is not None:
        return loaded
    seed = seed_from_config(cfg)
    return save(conn, seed, now), seed


def from_form(items: list[tuple[str, str]]) -> WatchSettings:
    """Build settings from the panel's form fields. Groups are keyed so removed groups leave no gaps."""
    def first(key: str) -> str:
        return next((v for k, v in items if k == key), "")

    def ints(key: str) -> tuple[int, ...]:
        return tuple(dict.fromkeys(int(v) for k, v in items if k == key))

    try:
        groups = []
        for key in dict.fromkeys(v for k, v in items if k == "group_key"):
            brands: dict[int, Brand] = {}
            for k, v in items:
                if k == f"brand_{key}":
                    brand_id, _, title = v.partition("|")
                    brands.setdefault(int(brand_id), Brand(int(brand_id), title.strip()))
            groups.append(Group(first(f"group_name_{key}").strip(), tuple(brands.values())))
        return WatchSettings(tuple(groups), ints("catalog_ids"), ints("size_ids"), ints("status_ids"))
    except ValueError as exc:
        raise SettingsError(["The form contained invalid data. Reload the panel and try again."]) from exc

"""Numbers, chart series, product rows and tracker state for the dashboard."""
from __future__ import annotations

from collections import defaultdict
from datetime import datetime, timedelta
from decimal import Decimal
from statistics import median
from zoneinfo import ZoneInfo

import psycopg

from .vinted_ref import PRODUCT_TYPES, catalog_ids_of_type, product_type_of

MIN_SOLD_PER_BAR = 3
PAGE_SIZE = 50
LOCAL_TZ = ZoneInfo("Europe/Bucharest")
STATUS_LABELS = {"tracking": "Tracking", "sold": "Sold", "deleted": "Deleted", "unsold_30d": "Unsold 30 d", "hidden": "Hidden"}

_HOURS = "(extract(epoch FROM (sold_after_min + sold_after_max) / 2) / 3600)::float8"


def tiles(conn: psycopg.Connection, now: datetime) -> dict:
    row = conn.execute(
        f"""
        SELECT count(*) FILTER (WHERE final_status IS NULL) AS tracking,
               count(*) FILTER (WHERE final_status = 'sold') AS sold,
               count(*) FILTER (WHERE final_status = 'deleted') AS deleted,
               percentile_cont(0.5) WITHIN GROUP (ORDER BY {_HOURS})
                   FILTER (WHERE final_status = 'sold' AND NOT uncertain) AS median_hours,
               count(*) FILTER (WHERE final_status = 'sold' AND sold_after_max <= interval '7 days'
                                AND %(now)s - uploaded_at >= interval '7 days') AS sold_7d,
               count(*) FILTER (WHERE %(now)s - uploaded_at >= interval '7 days') AS old_7d
        FROM items WHERE NOT out_of_scope
        """,
        {"now": now},
    ).fetchone()
    return {
        "tracking": row["tracking"],
        "sold": row["sold"],
        "deleted": row["deleted"],
        "median_hours": None if row["median_hours"] is None else round(row["median_hours"], 1),
        "pct_sold_7d": round(100.0 * row["sold_7d"] / row["old_7d"], 1) if row["old_7d"] else None,
    }


def price_band(price: Decimal | None) -> str:
    if price is None:
        return "(none)"
    for limit, label in ((50, "0-49 RON"), (100, "50-99 RON"), (200, "100-199 RON"), (400, "200-399 RON")):
        if price < limit:
            return label
    return "400+ RON"


def chart_series(conn: psycopg.Connection) -> dict[str, list[dict]]:
    rows = conn.execute(
        f"""
        SELECT brand, catalog_id, size, price_listed_ron, {_HOURS} AS hours FROM items
        WHERE NOT out_of_scope AND final_status = 'sold' AND NOT uncertain
        """
    ).fetchall()
    keys = {
        "brand": lambda r: r["brand"] or "(none)",
        "type": lambda r: product_type_of(r["catalog_id"]) or "(other)",
        "size": lambda r: r["size"] or "(none)",
        "price_band": lambda r: price_band(r["price_listed_ron"]),
    }
    series: dict[str, list[dict]] = {}
    for dim, key in keys.items():
        buckets: dict[str, list[float]] = defaultdict(list)
        for r in rows:
            buckets[key(r)].append(float(r["hours"]))
        series[dim] = sorted(
            (
                {"label": label, "median_hours": round(median(hours), 1), "count": len(hours)}
                for label, hours in buckets.items()
                if len(hours) >= MIN_SOLD_PER_BAR
            ),
            key=lambda b: (b["median_hours"], b["label"]),
        )
    return series


def distinct_brands(conn: psycopg.Connection) -> list[str]:
    rows = conn.execute(
        "SELECT DISTINCT brand FROM items WHERE NOT out_of_scope AND brand IS NOT NULL ORDER BY brand"
    ).fetchall()
    return [r["brand"] for r in rows]


def products(
    conn: psycopg.Connection,
    now: datetime,
    *,
    status: str = "",
    brand: str = "",
    type_id: int | None = None,
    q: str = "",
    page: int = 1,
    base_url: str = "https://www.vinted.ro",
) -> tuple[list[dict], int]:
    where = ["NOT i.out_of_scope"]
    params: dict = {"limit": PAGE_SIZE, "offset": (max(page, 1) - 1) * PAGE_SIZE}
    if status == "tracking":
        where.append("i.final_status IS NULL")
    elif status in STATUS_LABELS:
        where.append("i.final_status = %(status)s")
        params["status"] = status
    if brand:
        where.append("i.brand = %(brand)s")
        params["brand"] = brand
    if type_id in PRODUCT_TYPES:
        where.append("i.catalog_id = ANY(%(cats)s)")
        params["cats"] = list(catalog_ids_of_type(type_id))
    if q.strip():
        where.append("(i.title ILIKE %(q)s OR i.brand ILIKE %(q)s)")
        params["q"] = f"%{q.strip()}%"
    rows = conn.execute(
        f"""
        SELECT i.id, i.title, i.url, i.brand, i.catalog_id, i.size, i.condition, i.price_listed_ron,
               i.uploaded_at, i.final_status, i.sold_after_min, i.sold_after_max, i.uncertain,
               i.last_checked_at, i.next_check_at, lp.lowest_price, lp.favourites, count(*) OVER () AS total
        FROM items i
        LEFT JOIN LATERAL (
            SELECT min(o.price_ron) AS lowest_price,
                   (array_agg(o.favourite_count ORDER BY o.observed_at DESC)
                        FILTER (WHERE o.favourite_count IS NOT NULL))[1] AS favourites
            FROM observations o WHERE o.item_id = i.id
        ) lp ON true
        WHERE {' AND '.join(where)}
        ORDER BY i.uploaded_at DESC, i.id DESC
        LIMIT %(limit)s OFFSET %(offset)s
        """,
        params,
    ).fetchall()
    total = rows[0]["total"] if rows else 0
    return [_format(r, now, base_url) for r in rows], total


def _format(r: dict, now: datetime, base_url: str) -> dict:
    status = r["final_status"] or "tracking"
    return {
        "id": r["id"],
        "title": r["title"],
        "link": base_url + r["url"],
        "brand": r["brand"] or "",
        "type": product_type_of(r["catalog_id"]) or "",
        "size": r["size"] or "",
        "condition": r["condition"] or "",
        "status": status,
        "status_label": STATUS_LABELS.get(status, status),
        "price_text": _price_text(r["price_listed_ron"], r["lowest_price"]),
        "listed_ago": _ago(now - r["uploaded_at"]),
        "sold_after_text": _sold_after(r) if status == "sold" else "",
        "favourites": r["favourites"],
        "last_checked_ago": _ago(now - r["last_checked_at"]) if r["last_checked_at"] else "",
        "next_check_in": _in(r["next_check_at"] - now) if r["next_check_at"] and status == "tracking" else "",
    }


def _money(value: Decimal) -> str:
    return f"{value:.0f}" if value == value.to_integral_value() else f"{value:.2f}"


def _price_text(listed: Decimal | None, lowest: Decimal | None) -> str:
    if listed is None:
        return ""
    if lowest is not None and lowest < listed:
        return f"{_money(listed)} → {_money(lowest)} RON"
    return f"{_money(listed)} RON"


def _sold_after(r: dict) -> str:
    lo = r["sold_after_min"].total_seconds() / 3600
    hi = r["sold_after_max"].total_seconds() / 3600
    text = f"{lo:.0f}–{hi:.0f} h" if hi < 48 else f"{lo / 24:.1f}–{hi / 24:.1f} d"
    return ("≈ " if r["uncertain"] else "") + text


def _span(delta: timedelta) -> str:
    minutes = int(delta.total_seconds() // 60)
    if minutes < 60:
        return f"{minutes} min"
    if minutes < 48 * 60:
        return f"{minutes // 60} h"
    return f"{minutes // 1440} d"


def _ago(delta: timedelta) -> str:
    return "just now" if delta < timedelta(minutes=1) else f"{_span(delta)} ago"


def _in(delta: timedelta) -> str:
    return "now" if delta < timedelta(minutes=1) else f"in {_span(delta)}"


def tracker_state(row: tuple[dict, datetime] | None, now: datetime, stale_after: timedelta = timedelta(minutes=10)) -> dict:
    if row is None:
        return {"level": "stopped", "text": "Tracker hasn't reported yet", "blocks": None}
    data, updated = row
    blocks = (data.get("this_run") or {}).get("blocks")
    paused_until = datetime.fromisoformat(data["paused_until"]) if data.get("paused_until") else None
    if data.get("health") == "blocked" and paused_until and paused_until > now:
        until = paused_until.astimezone(LOCAL_TZ).strftime("%H:%M")
        return {"level": "warn", "text": f"Blocked by Vinted · pausing until {until}", "blocks": blocks}
    age = now - updated
    if age >= stale_after:
        return {"level": "stopped", "text": f"Tracker stopped (no check for {_span(age)})", "blocks": blocks}
    health = data.get("health", "ok")
    if health == "parser_broken":
        return {"level": "warn", "text": "Vinted pages changed: parsing fails, see debug/", "blocks": blocks}
    if health == "network_error":
        return {"level": "warn", "text": f"Pages not loading · {data.get('last_error') or ''}".strip(" ·"), "blocks": blocks}
    if health == "blocked":
        return {"level": "warn", "text": "Blocked by Vinted", "blocks": blocks}
    return {"level": "ok", "text": f"Running · last check {_ago(age)}", "blocks": blocks}
```

"""Search Vinted's brand list for the settings panel (cached; one short-lived browser per lookup)."""
from __future__ import annotations

import logging
import threading
import time
from contextlib import AbstractContextManager
from datetime import datetime, timedelta
from pathlib import Path
from typing import Callable

import psycopg

from . import db
from .browser import BlockedError, is_challenge
from .models import utcnow

log = logging.getLogger(__name__)
SearchFn = Callable[[str], list[dict]]
ConnFactory = Callable[[], AbstractContextManager[psycopg.Connection]]
FAILED_MESSAGE = "Vinted didn't answer, try again in a few minutes."


class LookupFailed(RuntimeError):
    pass


class BrandLookup:
    def __init__(
        self,
        conn_factory: ConnFactory,
        search: SearchFn,
        *,
        clock: Callable[[], datetime] = utcnow,
        min_interval_s: float = 5.0,
        cache_days: int = 30,
        sleep: Callable[[float], None] = time.sleep,
        monotonic: Callable[[], float] = time.monotonic,
    ) -> None:
        self._conn_factory, self._search = conn_factory, search
        self._clock, self._min_interval_s, self._cache_age = clock, min_interval_s, timedelta(days=cache_days)
        self._sleep, self._monotonic = sleep, monotonic
        self._lock = threading.Lock()
        self._last: float | None = None

    def search(self, keyword: str) -> list[dict]:
        key = keyword.strip().casefold()
        if len(key) < 2:
            return []
        with self._conn_factory() as conn:
            cached = db.get_brand_cache(conn, key)
        if cached is not None and self._clock() - cached[1] < self._cache_age:
            return cached[0]
        with self._lock:
            if self._last is not None:
                wait = self._last + self._min_interval_s - self._monotonic()
                if wait > 0:
                    self._sleep(wait)
            try:
                results = self._search(key)
            except Exception as exc:
                log.warning("brand lookup for %r failed: %s", key, exc)
                raise LookupFailed(FAILED_MESSAGE) from exc
            finally:
                self._last = self._monotonic()
        with self._conn_factory() as conn:
            db.put_brand_cache(conn, key, results, self._clock())
        return results


def playwright_brand_search(profile_dir: Path, base_url: str) -> SearchFn:
    def search(keyword: str) -> list[dict]:
        from playwright.sync_api import sync_playwright

        with sync_playwright() as p:
            ctx = p.chromium.launch_persistent_context(
                str(profile_dir), headless=True, locale="ro-RO", timezone_id="Europe/Bucharest"
            )
            try:
                page = ctx.pages[0] if ctx.pages else ctx.new_page()
                response = page.goto(f"{base_url}/catalog", wait_until="domcontentloaded", timeout=45_000)
                if is_challenge(response.status if response else 0, page.content()):
                    raise BlockedError("challenge during brand lookup")
                data = page.evaluate(
                    """async (kw) => {
                        const r = await fetch('/api/v2/brands?keyword=' + encodeURIComponent(kw),
                                              {headers: {accept: 'application/json'}});
                        if (!r.ok) throw new Error('HTTP ' + r.status);
                        return await r.json();
                    }""",
                    keyword,
                )
            finally:
                ctx.close()
        return [
            {"id": int(b["id"]), "title": str(b["title"]), "item_count": int(b.get("item_count") or 0)}
            for b in (data.get("brands") or [])[:10]
        ]

    return search
```

Note on `test_searches_are_spaced_out`: `monotonic` is frozen at 1000.0, so the second search computes `wait = 1000 + 5 - 1000 = 5.0` and sleeps exactly 5.0.

"""Dashboard: one page, htmx fragments, settings panel, Excel download. Local only (127.0.0.1)."""
from __future__ import annotations

import io
from contextlib import AbstractContextManager
from datetime import datetime
from pathlib import Path
from typing import Callable

import psycopg
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, JSONResponse, Response
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

from .. import db, stats
from ..brand_lookup import BrandLookup
from ..export import build_report, write_report
from ..models import utcnow
from ..vinted_ref import PRODUCT_TYPES

HERE = Path(__file__).resolve().parent
XLSX = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
STATUS_FILTERS = tuple(stats.STATUS_LABELS.items())
ConnFactory = Callable[[], AbstractContextManager[psycopg.Connection]]


def create_app(
    conn_factory: ConnFactory,
    lookup: BrandLookup,
    *,
    base_url: str = "https://www.vinted.ro",
    clock: Callable[[], datetime] = utcnow,
) -> FastAPI:
    app = FastAPI(title="Vinted tracker", docs_url=None, redoc_url=None, openapi_url=None)
    app.mount("/static", StaticFiles(directory=HERE / "static"), name="static")
    templates = Jinja2Templates(directory=HERE / "templates")

    def render(request: Request, name: str, **context) -> HTMLResponse:
        return templates.TemplateResponse(request, name, context)

    @app.get("/", response_class=HTMLResponse)
    def page(request: Request):
        try:
            with conn_factory() as conn:
                brands = stats.distinct_brands(conn)
        except psycopg.OperationalError:
            brands = []
        return render(request, "page.html", brands=brands, types=list(PRODUCT_TYPES.items()), statuses=STATUS_FILTERS)

    @app.get("/fragments/status", response_class=HTMLResponse)
    def status_fragment(request: Request):
        try:
            with conn_factory() as conn:
                row = db.get_tracker_status(conn)
        except psycopg.OperationalError:
            return render(request, "_db_error.html")
        return render(request, "_status.html", state=stats.tracker_state(row, clock()))

    @app.get("/fragments/tiles", response_class=HTMLResponse)
    def tiles_fragment(request: Request):
        try:
            with conn_factory() as conn:
                tiles = stats.tiles(conn, clock())
        except psycopg.OperationalError:
            return render(request, "_db_error.html")
        return render(request, "_tiles.html", t=tiles)

    @app.get("/api/charts")
    def charts():
        try:
            with conn_factory() as conn:
                return stats.chart_series(conn)
        except psycopg.OperationalError:
            return JSONResponse({}, status_code=503)

    @app.get("/fragments/products", response_class=HTMLResponse)
    def products_fragment(request: Request, status: str = "", brand: str = "", type: str = "", q: str = "", page: int = 1):
        type_id = int(type) if type.isdigit() else None
        try:
            with conn_factory() as conn:
                rows, total = stats.products(conn, clock(), status=status, brand=brand, type_id=type_id, q=q,
                                             page=page, base_url=base_url)
        except psycopg.OperationalError:
            return render(request, "_db_error.html")
        pages = max(1, -(-total // stats.PAGE_SIZE))
        return render(request, "_products.html", rows=rows, total=total, page=min(page, pages), pages=pages)

    @app.get("/export.xlsx")
    def export():
        try:
            with conn_factory() as conn:
                frames = build_report(conn, base_url)
        except psycopg.OperationalError:
            return Response("Can't reach the database.", status_code=503, media_type="text/plain")
        buffer = io.BytesIO()
        write_report(frames, buffer)
        name = f"vinted_report_{clock().date().isoformat()}.xlsx"
        return Response(buffer.getvalue(), media_type=XLSX, headers={"Content-Disposition": f'attachment; filename="{name}"'})

    return app

      CHARTS[dim].update();

function addBrand(button) {
  const key = button.dataset.group;
  const id = button.dataset.id;
  const title = button.dataset.title;
  const box = document.getElementById('brands-' + key);
  if (!box) return;
  const already = [...box.querySelectorAll('input[type=hidden]')].some((i) => i.value.split('|')[0] === id);
  if (!already) {
    const chip = document.createElement('span');
    chip.className = 'chip';
    const input = document.createElement('input');
    input.type = 'hidden';
    input.name = 'brand_' + key;
    input.value = id + '|' + title;
    const remove = document.createElement('button');
    remove.type = 'button';
    remove.className = 'x';
    remove.title = 'Remove';
    remove.textContent = '✕';
    remove.onclick = () => chip.remove();
    chip.append(input, document.createTextNode(title + ' '), remove);
    box.appendChild(chip);
  }
  button.closest('.results').innerHTML = '';
}

function addGroup() {
  const key = 'n' + Date.now();
  const html = document.getElementById('group-template').innerHTML.replaceAll('__KEY__', key);
  const groups = document.getElementById('groups');
  groups.insertAdjacentHTML('beforeend', html);
  htmx.process(groups.lastElementChild);
  groups.lastElementChild.querySelector('input[name^="group_name_"]').focus();
}

def port_is_free(port: int) -> bool:
    with socket.socket() as probe:
        try:

        except OSError:

def cmd_dashboard(cfg: Config, args: argparse.Namespace) -> int:
    import uvicorn

    from .brand_lookup import BrandLookup, playwright_brand_search
    from .web.app import create_app

    if not port_is_free(args.port):
        print(f"Port {args.port} is already in use (is the dashboard already running?). Try --port {args.port + 1}.")
        return 1
    with db.connect(cfg.database_url) as conn:
        db.init_schema(conn)
        watch_settings.ensure_seeded(conn, cfg, utcnow())

    def connect():

    lookup = BrandLookup(connect, playwright_brand_search(LOOKUP_PROFILE_DIR, cfg.base_url))
    app = create_app(connect, lookup, base_url=cfg.base_url)
    print(f"Dashboard: http://localhost:{args.port}  (Ctrl+C to stop)")
    uvicorn.run(app, host="127.0.0.1", port=args.port, log_level="warning")

$root = Split-Path -Parent $PSScriptRoot
$action = New-ScheduledTaskAction -Execute "conhost.exe" `
    -Argument "--headless powershell.exe -NoProfile -ExecutionPolicy Bypass -File `"$root\scripts\run_dashboard.ps1`"" `
    -WorkingDirectory $root
$trigger = New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries `
    -ExecutionTimeLimit ([TimeSpan]::Zero) -MultipleInstances IgnoreNew
Register-ScheduledTask -TaskName "VintedDashboard" -Action $action -Trigger $trigger -Settings $settings `
    -Description "Vinted tracker dashboard on http://localhost:8000" -Force
Write-Host "Registered. Start now with: Start-ScheduledTask -TaskName VintedDashboard"
```
